One line of out-of-office auto-reply, the funniest I can make it, in 140
characters or fewer. A reply a real person would set: it does not just say
the sender is away, it pre-emptively denies that anything is urgent — and
then proves it, because they checked twice before leaving.

> I'm away until Monday. If this is urgent, it isn't. I checked twice before I left.

## Run it

```sh
python3 main.py
```

`main.py` writes the line to `entry.txt` in the directory named by
`MAKEFUN_OUTPUT_DIR` (or `/output` when unset). Stdlib only.
